A one-line entry (116 characters) inventing the most useless superpower: teleportation, shrunk to a three-centimetre hop to the left, once a day, always landing facing the wrong way. The program in `main.ts` writes the line to `entry.txt` in the output directory and refuses to write anything that is not one line of 1 to 140 characters.

> I can teleport anywhere, but only three centimetres to the left, once a day, and I always land facing the wrong way.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
